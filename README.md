# Epic Fight Tinker Compat

Source code for **Epic Fight Tinker Compat**, a Minecraft Forge mod that integrates **Tinkers' Construct** with **Epic Fight**.

## Features

* Makes Tinkers' Construct tools work properly with Epic Fight weapon categories and movesets.
* Adds Epic Fight combat stats to Tinkers' tools and armor.
* Integrates various Tinkers' modifiers with Epic Fight mechanics.
* Fixes compatibility and visual issues between both mods.
* Includes additional combat effects, weapon trails, and quality-of-life improvements.

## Downloads

* CurseForge: https://www.curseforge.com/minecraft/mc-mods/epic-fight-tinker-compat
* Modrinth: https://modrinth.com/mod/epic-fight-tinker-compat

## Requirements

* Minecraft 1.20.1
* Forge
* Epic Fight
* Tinkers' Construct
